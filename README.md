# Higvid website

Static website for GitHub Pages. The domain in `CNAME` is `higvid.com`.

## Publish changes

1. Upload the contents of this folder to the root of the GitHub repository used for GitHub Pages. Keep the `CNAME` file.
2. Commit the changes. GitHub Pages will publish the updated site from the configured branch.
3. Check the live site on a phone and a desktop.

## Site pages

- `index.html` — landing page
- `features.html` — feature walkthrough using the supplied app screens
- `contact.html` — support options opening an email to `contact@higvid.com`
- `privacy.html` — privacy policy

The contact page uses email links because GitHub Pages cannot process a contact form by itself.

The App Store button in `index.html` links to `https://apps.apple.com/us/app/id1375267426`.
